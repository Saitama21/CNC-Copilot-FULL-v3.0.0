CNC COPILOT FULL v3.0.2

PWA с локальным ядром.

Локально без API:
- расчёты и пятишаговый техпроцесс
- материалы и цветовые карточки ISO
- умный шкаф и мультивыбор инструмента
- проекты, требования чертежа, допуски и резьбы
- резервные копии JSON и печать/PDF

Онлайн только по ручному включению:
- Face ID / Passkey серверная авторизация
- ИИ-распознавание инструмента до 4 фото
- синхронизация шкафа, проектов и профиля станка через Railway/PostgreSQL

После онлайн-привязки доверенного устройства локальный экран может запросить Face ID / Passkey даже без доступа к Railway.

Версия: FULL 3.0.2
