# WIP-08 · Tool assignment audit

Контрольный сценарий: наружное точение AISI 304, Ø50 → Ø43, режим «Черновая + чистовая».

Ожидаемое поведение:
1. Черновой проход получает только инструмент с `passes` содержащим `rough`.
2. Чистовой проход получает только инструмент с `passes` содержащим `finish`.
3. Каталожный WNMG 080408-MM (rough-only) не может попасть в чистовой проход.
4. При доступном наборе Copilot показывает отдельный план, например: `Черновой WNMG 080408-MM → чистовой CCMT 09T304`.
5. Если пользователь вручную назначил старый единый инструмент, миграция переносит его только в совместимый проход, второй остаётся `auto`.
6. Старые пользовательские инструменты с автоматически выданным профилем `rough + finish + single` не считаются подтверждёнными до явного выбора «Черн. / Чист. / Оба» в шкафу.
7. Без совместимого инструмента для любого прохода кнопка перехода к стратегии/расчёту остаётся заблокированной.

Regression: auth + calc + UI = 79/79.
