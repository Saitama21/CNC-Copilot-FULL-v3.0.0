# CNC Copilot FULL 3.1 · WIP-07 scenario audit

Контрольный сценарий: AISI 304, заготовка Ø50 × 145 мм, торцовка + наружное точение Ø50 → Ø43, рабочая стратегия, эмульсия, средняя жёсткость.

Проверено по логике сборки:
1. Новый проект не содержит демо-размеров.
2. Без материала/Ø/длины дальше пройти нельзя; HB необязателен.
3. Выбранные операции идут в заданном порядке.
4. На шаге размеров будущая операция заблокирована, пока текущая не заполнена.
5. Ø50 → Ø43 трактуется как 3.5 мм радиального съёма. Для режима «черновая + чистовая» припуск автоматически делится между чистовым припуском и рассчитанным числом черновых проходов.
6. Если feedback уменьшает ap, Copilot пересчитывает и количество проходов этой же операции.
7. Чистовой feedback заблокирован до подтверждения чернового режима.
8. Перед расчётом показывается сводка геометрии, инструмента, G96 LIMS и мощности.
9. Результаты открываются по одной операции; следующая — только после подтверждения текущей.
10. Ограничения CK52PT-Y из WIP-04 сохранены.
